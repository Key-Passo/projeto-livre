# 📝 Agenda de Anotações — KeyPasso

## 📌 Sobre o projeto
A Agenda de Anotações é o projeto livre do KeyPasso, desenvolvido como parte do projeto final da disciplina de Programação Orientada a Objetos (POO).

O sistema tem como objetivo permitir que o usuário organize e gerencie suas anotações de forma simples e prática.

## 🎯 Objetivo
Desenvolver uma aplicação utilizando os conceitos de Programação Orientada a Objetos, contribuindo para a integração e organização dos módulos do KeyPasso.

## 🖥️ Funcionalidades
- Cadastro de anotações;
- Visualização de anotações;
- Edição de anotações;
- Exclusão de anotações;
- Organização das informações;
- Interface gráfica.

## 🛠️ Tecnologias
- Java
- Java Swing
- Programação Orientada a Objetos
- Git
- GitHub
